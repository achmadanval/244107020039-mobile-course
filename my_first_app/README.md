## Pertanyaan 

1.Kapan native lebih tepat dipilih daripada cross-platform?

Native lebih tepat dipilih ketika aplikasi membutuhkan akses penuh ke fitur perangkat keras dan perangkat lunak, serta membutuhkan performa yang optimal. Selain itu, native lebih tepat dipilih ketika aplikasi membutuhkan integrasi yang mendalam dengan sistem operasi.

2.Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?

Karena perubahan state pada aplikasi akan mempermudah kita dalam melacak perubahan yang terjadi pada aplikasi, serta mempermudah untuk memahami perubahan yang terjadi pada aplikasi dan commit kecil dengan pesan yang jelas akan mempermudah untuk menemukan bug yang terjadi pada aplikasi.
